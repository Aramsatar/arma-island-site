Privacy

ARMA Island collects nothing, sends nothing, and has no account.

Last updated 30 July 2026

That is not a promise about intent — it is a property of how the app is built. There is no networking code in it at all. It makes no requests, opens no connections, and holds no sockets while running. There is no server for it to talk to.

What it reads, and where that stays

  • Agent sessions — read from a folder on your own disk that Claude Code writes to, at ~/Library/Application Support/ARMA Island/sessions/.
  • Now playing — asked of Spotify, Music or Chrome on your Mac, via Apple Events.
  • Clipboard history — kept in a file on your Mac. Items a password manager marks as concealed are skipped. You can clear it or switch it off.

All of it stays on your machine. None of it is transmitted, because nothing in the app can transmit.

Your licence

Licence keys are verified offline using a signature. Activating one involves no network request, so we do not learn that you installed it, when you run it, or how you use it. The trade is deliberate: a check that phoned home would need a server, a server would need an account, and the promise above would be gone.

Analytics, telemetry, crash reports

None. There is no third-party SDK in the app.

If you email us

Buying a licence today means emailing us, so we will hold your email address in order to send you a key and honour it later. Nothing more, and it is not shared.

Changes

If this ever stops being true, this page changes first and the reason is stated plainly.
